技能列表（23）

active-scan
主动端口与服务扫描（nmap/masscan），严格遵守授权范围。
asset-correlation
资产关联：域名↔IP↔C 段↔证书↔服务的图谱化。
browser-automation
无依赖驱动 Chrome 抓取 JS 渲染页面、截图、执行 JS、抓接口清单。
chisel-tunnel
HTTP/WebSocket 封装的多路复用隧道，穿透出网限制与反向代理。
cn-proxy-pool
国内免费 HTTP/SOCKS5 代理池：抓取、验活、按需轮换。
credential-attack
在线弱口令爆破（hydra）与离线哈希破解（hashcat/john）。
dir-bruteforce
目录与文件爆破：后台入口、备份文件、配置泄露、源码暴露。
fofa-recon
用 FOFA API 批量测绘靶标资产，内置限速客户端。
frp-tunnel
frp 内网穿透：VPS 跑 frps，目标跑 frpc，得到 socks5 与端口转发。
fscan-intranet
fscan v2.2.1 内网综合扫描：存活、端口/服务、弱口令、未授权。
gogo-intranet
gogo v2.15.0 高性能内网扫描：智能模式、主动+被动指纹。
kimi-webbridge
用 Kimi 浏览器扩展（WebBridge）驱动真实 Chrome 完成操作。
lateral-movement
内网横向与提权：Impacket 套件（PtH/PsExec/WMI/DCOM/Kerberos）。
nuclei-scan
模板化漏洞扫描：13,000+ 模板覆盖 CVE/暴露面/配置缺陷。
passive-recon
被动信息收集：不接触目标主机，仅用公开数据源。
recon-pipeline
ProjectDiscovery 流水线：subfinder→dnsx→naabu→httpx→katana。
redteam-setup
首次使用引导：FOFA_KEY、VPS 登录方式、通道验证、降级方案。
shell-handler
反弹 Shell 与载荷投递：MSF/nc/socat 监听接收 shell。
suo5-tunnel
通过 WebShell/HTTP 建立 SOCKS5 隧道，把内网流量代理出来。
unauth-exploit
未授权访问与信息泄露利用链：Redis/MySQL/MSSQL/ES/Docker/MongoDB。
vps-reverse-shell
自建 VPS 做反弹 Shell 落地与中转，9000-9999 端口规划。
web-fingerprint
Web 服务指纹识别：框架、中间件、CMS、组件版本。
webshell-toolkit
冰蝎 / 哥斯拉 / 中国蚁剑 的启动与用法，管理 WebShell。
